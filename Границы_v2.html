Делаем / Не делаем

✅ Делаем — проверено

• Роутинг по 3 осям: безопасность, стоимость, отказоустойчивость

• PII: паспорт, СНИЛС, телефон, email, карта (Luhn), счёт

• Injection RU + EN → HTTP 403

• Fallback: LLM упал → CPU, audit llm_fallback

• Кэш изолирован по tenant, sensitive на CPU

• Entity Guard: PII → не кэшируется (main path)

• NER для имён: natasha, PII_NER=1 (локально)

• Audit без PII: prompt_hash, не текст

• 96 unit + 16 HTTP + 49 PII + 14 evals

• On-prem, loopback, ноль внешних endpoint'ов

⚠️ Не делаем — и план

• Injection не RU/EN → пилот: под ваш корпус

• «Забудь всё» не ловится → расширение паттернов

• PII под ваш бизнес (ИНН, БИК, KYC) → пилот

• SLA 24/7 → после пилота, отдельный договор

• Docker/CI → 1–2 дня на пилоте

• Замена ИБ → мы слой, не замена

• Coverage % → метрика пилота

• Обучение команды → 2 сессии на пилоте

Границы знаем заранее — не обещаем «всё»
